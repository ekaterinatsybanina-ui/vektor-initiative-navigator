# ВЕКТОР 2.0 — навигатор научных и образовательных инициатив

ВЕКТОР — учебный Python-проект для специалистов по проектной деятельности. Помогает проводить первичную экспертную оценку инициатив в сфере науки, образования и технологического предпринимательства, вести единый портфель и определять следующие шаги сопровождения.

## Что умеет приложение

- **Обзор портфеля:** ключевые показатели, средняя готовность, активные инициативы и зона внимания.
- **Экспертная оценка:** семь критериев с весами, расчёт индекса готовности от 0 до 100%.
- **План сопровождения:** автоматические предложения по трём самым слабым критериям.
- **Банк инициатив:** поиск, фильтрация по направлению и статусу, изменение статусов, удаление записей.
- **Аналитика:** диаграммы по готовности и статусам, сводный реестр.
- **Экспорт:** CSV, JSON-резервная копия и паспорт отдельной инициативы в Markdown.
- **Хранение:** данные сохраняются в `data/initiatives.json`.

## Модель оценки

| Критерий | Вес |
|---|---:|
| Актуальность проблемы | 20% |
| Потенциальный эффект | 20% |
| Целевая аудитория | 15% |
| Готовность к реализации | 15% |
| Компетенции команды | 10% |
| Ресурсное обеспечение | 10% |
| Масштабируемость | 10% |

Каждый критерий оценивается от 1 до 5. Индекс рассчитывается как сумма произведений баллов на веса, делённая на 5.

- 80–100% — высокая готовность;
- 60–79% — перспективная инициатива, нужна точечная доработка;
- 40–59% — рекомендуется методическое сопровождение;
- 0–39% — требуется существенная проработка.

**Важно:** индекс — прозрачная экспертная балльная модель, а не результат полноценного ИИ, не прогноз успеха и не автоматическое решение о финансировании. Рекомендации носят справочный характер.

## Запуск локально

Нужен Python 3.10 или новее.

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

Установите зависимости и запустите:

```bash
pip install -r requirements.txt
streamlit run app.py
```

После запуска Streamlit покажет локальный адрес приложения (обычно `http://localhost:8501`).

## Публикация на GitHub

1. Откройте https://github.com и войдите в аккаунт.
2. Нажмите **New repository**.
3. Название: `vektor-initiative-navigator`.
4. Выберите **Public**, если преподаватель должен видеть репозиторий.
5. Нажмите **Create repository**.
6. Выберите **Add file → Upload files**.
7. Загрузите содержимое папки проекта (файлы `app.py`, `requirements.txt`, `README.md`, `.gitignore` и папку `data`).
8. Нажмите **Commit changes**.

Не загружайте виртуальное окружение `.venv`, пароли, токены и персональные данные.

## Публикация приложения в интернете

GitHub хранит исходный код, но не запускает приложение. Для демонстрации можно использовать Streamlit Community Cloud:

1. Откройте https://share.streamlit.io/ и войдите через GitHub.
2. Нажмите **Create app**.
3. Выберите репозиторий `vektor-initiative-navigator`, ветку `main` и файл `app.py`.
4. Нажмите **Deploy**.

Для постоянной многопользовательской эксплуатации потребуется общая база данных. Текущее JSON-хранилище предназначено для учебного прототипа и локальной демонстрации.
