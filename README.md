# ВЕКТОР — навигатор научных и образовательных инициатив

Учебный прототип на Python + Streamlit с премиальной визуальной концепцией: графит, тёплый молочный фон, приглушённый сливовый, лавандовый и оттенок шампанского. Помогает специалисту провести первичную экспертную оценку инициативы, определить уровень её готовности и выбрать следующий шаг сопровождения.

## Возможности
- Главная панель с ключевыми показателями портфеля.
- Карточка инициативы и оценка по 7 критериям.
- Взвешенный индекс готовности (0–100%).
- Рекомендации по дальнейшим действиям.
- Банк инициатив: поиск, фильтры, изменение статусов и удаление.
- Аналитика, диаграммы, экспорт CSV и резервная копия JSON.
- Сохранение записей в `data/initiatives.json`.

## Алгоритм оценки
Каждый критерий оценивается от 1 до 5. Итоговый индекс рассчитывается как сумма произведений баллов на вес критериев, делённая на 5.

| Критерий | Вес |
|---|---:|
| Актуальность проблемы | 20% |
| Потенциальный эффект | 20% |
| Целевая аудитория | 15% |
| Готовность к реализации | 15% |
| Компетенции команды | 10% |
| Ресурсное обеспечение | 10% |
| Масштабируемость | 10% |

Интерпретация:
- 80–100: высокая готовность;
- 60–79: перспективная инициатива, нужна точечная доработка;
- 40–59: рекомендуется методическое сопровождение;
- 0–39: требуется существенная проработка.

**Важно:** индекс — прозрачная экспертная балльная модель, а не результат полноценного ИИ, не прогноз успеха и не автоматическое решение о финансировании. Рекомендации носят справочный характер.

## Запуск на компьютере

Нужен Python 3.10 или новее.

1. Распакуйте архив проекта.
2. Откройте терминал в папке `vektor_project`.
3. Создайте виртуальное окружение (необязательно, но рекомендуется):

```bash
python -m venv .venv
```

Windows:
```bash
.venv\Scripts\activate
```

macOS/Linux:
```bash
source .venv/bin/activate
```

4. Установите зависимости:

```bash
pip install -r requirements.txt
```

5. Запустите:

```bash
streamlit run app.py
```

Приложение откроется в браузере по адресу, который покажет Streamlit (обычно `http://localhost:8501`).

## Публикация на GitHub

### Через сайт GitHub — самый простой способ
1. Войдите в свой аккаунт на https://github.com.
2. Нажмите **New repository** (или `+` → **New repository**).
3. Название: `vektor-initiative-navigator`.
4. Выберите **Public**, чтобы преподаватель мог открыть проект.
5. Нажмите **Create repository**.
6. На странице нового репозитория нажмите **Add file → Upload files**.
7. Перетащите файлы и папки из распакованной папки проекта. Загрузите `app.py`, `requirements.txt`, `README.md`, `.gitignore` и папку `data`.
8. Нажмите **Commit changes**.

Не загружайте `.venv`, пароли, токены или персональные данные.

### Через Git (если установлен)
В терминале, открытом в папке проекта:

```bash
git init
git add .
git commit -m "Initial release: VEKТOR initiative navigator"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/vektor-initiative-navigator.git
git push -u origin main
```

Замените `ВАШ_ЛОГИН` на свой логин GitHub. Если GitHub попросит авторизацию, следуйте инструкции в браузере.

## Публикация приложения в интернете (Streamlit Community Cloud)
GitHub хранит исходный код, но сам по себе не запускает приложение.

1. Откройте https://share.streamlit.io/ и войдите через GitHub.
2. Нажмите **Create app**.
3. Выберите репозиторий `vektor-initiative-navigator`, ветку `main` и главный файл `app.py`.
4. Нажмите **Deploy**.
5. После сборки появится публичная ссылка — её можно отправить преподавателю вместе со ссылкой на GitHub.

Для демонстрационного проекта JSON-хранилища достаточно. Для постоянной эксплуатации несколькими пользователями потребуется подключить общую базу данных: локальный JSON-файл не предназначен для конкурентной работы и может сбрасываться/не сохраняться в некоторых облачных сценариях.
